# Face Recognition Attendance System

## Overview

A Flask and OpenCV based attendance management system that uses face recognition for student login and attendance tracking.

## Features

* Student Face Registration
* Face Recognition Login
* Attendance Tracking
* Admin Dashboard
* Student Dashboard
* SQLite Database
* Attendance Reports

## Technologies Used

* Python
* Flask
* OpenCV
* SQLite
* HTML
* CSS
* JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
```

## Usage

### Register Student

```bash
python register.py
```

### Train Model

```bash
python train.py
```

### Start Recognition

```bash
python recognize.py
```

### Run Flask Application

```bash
python app.py
```
